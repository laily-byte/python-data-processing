**Student Grades Data Analysis**

A program based on real data taken from my experience as a high school math teacher

**What the program does:**
- Reads student grades from a CSV file
- Cleans and prepares numeric data
- Calculates:
  - Averages per exam
  - Highest grades and corresponding student(s)
- Handles edge cases such as:
  - Multiple students with the same top score
  - Formatting numeric output for readability

**Concepts practiced:**
- File handling (CSV)
- Data cleaning
- Pandas basics (`read_csv`, `mean`, `max`, filtering)
- Data presentation and formatting
  
This repository is part of my learning journey toward working in tech, with a particular interest in:
- Data processing
- Quality assurance
- Working with real-world, imperfect data

The code may not be perfect, but it reflects my understanding, experimentation, and growth.
